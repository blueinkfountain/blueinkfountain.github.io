# 정정: 디자인·문서 구성 변경 철회

사용자의 파일 관리 요청을 디자인 변경으로 잘못 확대했다. 아래 초기 결과 중 디자인·메뉴·PDF 표시 변경은 철회했다.

- `_includes/head_custom.html`과 기존 Markdown 문서 내용을 최초 백업 그대로 복원.
- 임의로 다시 노출한 Solution 목차와 Bartle 페이지를 원래 비노출 상태로 복원.
- 공통 PDF 레이아웃·신규 공통 CSS 제거, 기존 PDF 뷰어와 필기 인라인 스타일 복원.
- 원래 폰트 URL과 원격 테마 설정 복원.
- 파일 정리, 계산 캐시·복구, 실제 코드 테스트는 유지.
- 별도 작업의 ODE 업그레이드는 보존.
- 기존 콘텐츠의 미완성 링크 진단은 참고용으로 변경. 디자인·구성 변경을 강제하지 않음.

# 2026-10-12 블로그 정리 결과

## 백업

- 위치: `/Users/persist/math-blog-backups/2026-10-12-before-cleanup/math-blog`
- 일반 파일 19,306개, 6,068,413,017바이트. 디렉터리·심볼릭 링크 포함 22,032개 항목.

- 백업 검증 후에만 프로젝트 파일 수정 시작.

## 변경

- 게시 페이지의 부모 연결·풀이 목차 복구, 제어문자 파일명 2개 수정.
- PDF 페이지 64개를 `_layouts/pdf.html` + `pdf` 메타데이터로 통합.
- PDF가 지정되지 않았던 One-Point Compactification 개요는 준비 중으로 표시. 임의의 다른 PDF로 대체하지 않음.
- 공통 CSS와 필기 CSS 분리, 모바일 내비게이션 복구, MathJax 설정을 로더 앞에 배치.
- 실제 코드 원본과 테스트 통합. 기존 설치 자료·`.before-*`·LaTeX 보조/원본은 `.archive/2026-10-12/`로 이동하여 보존.
- 폰트는 `assets/fonts/`로 이동. 기존 공개 PDF 자체와 일반 페이지 URL은 유지.
- 제어문자가 있던 Sylow/Munkres 페이지 두 개는 정상 파일명 URL로 변경.
- PDF 내용·알고리즘·기준 파일·라이브러리 버전별 계산 캐시 추가.
- 변경 없는 PDF를 재사용하고 새 PDF/YAML을 준비·검증 후 교체. 실패 롤백·다음 실행 복구·동시 갱신 잠금 추가.
- 기록 입력창도 같은 잠금을 사용하며, 기록을 읽기 전에 미완료 갱신을 복구.
- 의존성 목록과 Ruby lockfile, README 작성. PR 검사/빌드와 main 배포 분리.
- 소스 검사뿐 아니라 생성된 모든 HTML의 로컬 링크와 개발 파일 배포 제외를 CI에서 검사.

## 검증

- Python 34개 / JavaScript 34개 테스트 통과.
- 실제 Jekyll 3.10 / Just the Docs 0.12 빌드 성공.
- 데스크톱 1280px에서 가로 넘침·사이드바 잘림 없음, 모바일 390px에서 메뉴 열기와 필기 목록 표시 확인.
- 생성 HTML 98개에 대해 로컬 링크와 배포 경계 검사 통과.

## 운영 메모

- 변경은 로컬 작업 폴더에 있으며 Git commit/push/deploy는 실행하지 않음.
- 작업 도중 외부에서 추가된 `ode_lab_dynamics_upgrade/` 내용은 변경하지 않았으며 게시 대상에서 제외.
- 브라우저에 PDF 표시 기능이 없으면 공통 화면의 Open PDF / Download PDF로 열 수 있음.
- 오래된 Ruby 라이브러리의 Ruby 3.4 대비 경고가 있으나 검증 환경은 Ruby 3.3이며 빌드는 성공함.
